# azovunlocker

Windows-програма на Rust (eframe), яка запускає «фіктивні» ігри, щоб Discord бачив їх як запущені, автоматично виконує квести Discord (відео та ігрові) і фармить час перегляду трансляцій.

## Можливості
- **Ігри** — пошук у базі ігор Discord (~25 тис.) і запуск гри на вказаний час (секунди / хвилини / години або без обмеження); облік зіграного часу.
  - Ігри з exe: фіктивний процес за шляхом exe гри (0% CPU, ~300 КБ ОЗП; вікно невидиме — його немає ні на екрані, ні в панелі задач, ні в Alt+Tab).
  - Ігри без exe (позначка **RPC**: консольні, SDK тощо): через Rich Presence локального Discord — потрібен запущений Discord на ПК.
- **Фарм**
  - **Унікальні ігри** — пачками запускає ігри, яких ще немає в статистиці, щоб зростала кількість зіграних ігор. Фільтри «лише демо», «без 18+».
  - **Перегляд трансляції** — другий акаунт (його токен вводиться на цій вкладці) дзвонить основному в ЛС і транслює картинку з годинником, основний дивиться. Усе відбувається в одному прихованому браузері (системний WebView2): ваш Discord не потрібен і не змінюється. Акаунти самі додаються в друзі (Discord дозволяє дзвінки лише між друзями). Рахується тільки час, коли основний акаунт справді отримує відео.
- **Квести** — завантаження актуальних квестів, фільтр за типом завдання (відео ПК / з телефону / гра) і нагородою (Orbs, косметика, предмети), паралельне виконання.
- **Активні** — картка кожного квесту, гри та трансляції зі станом і прогресом, журнал.
- Обережна робота з лімітами Discord: заголовки `X-RateLimit-*`, повтор після 429, спільний кеш списку квестів.
- Легка: інтерфейс перемальовується лише з вибраною частотою кадрів і стає на паузу у фоні; трансляція обох акаунтів — ~650 МБ ОЗП.
- Надійна: файли налаштувань і статистики записуються атомарно (тимчасовий файл → скидання на диск → заміна), тож збій системи не зіпсує `settings.json` / `played.json`.

## Вимоги
- Windows 10/11 x64.
- [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/) — для перегляду трансляції (у Windows 11 уже встановлений).

## Збірка
Потрібен [Rust](https://rustup.rs/) (stable, MSVC).

```
cargo build --release
```

Готовий файл: `target\release\discordunlocker.exe`. Поруч із ним програма створює `settings.json`, `played.json`, `stream.json`, `detectable_v3.json` і папки `games\` та `web\`.

## ⚠ Важливо
- Токени акаунтів Discord зберігаються у `settings.json` відкритим текстом, а в папці `web\` — увійдені сесії браузера. **Ніколи не публікуйте ні цей файл, ні цю папку.**
- Використання токена користувача в сторонніх програмах порушує умови користування Discord; акаунти можуть заблокувати. Використовуєте на власний ризик.
