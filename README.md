# discordunlocker

Windows-програма на Rust (eframe), яка запускає «фіктивні» ігри, щоб Discord бачив їх як запущені, і автоматично виконує квести Discord (відео та ігрові).

## Можливості
- **Ігри** — пошук у базі ігор Discord і запуск фіктивного процесу гри (0% CPU, вікно приховане); облік зіграного часу.
- **Квести** — завантаження актуальних квестів, фільтр за типом завдання (відео ПК / з телефону / гра) і нагородою (Orbs, косметика, предмети), паралельне виконання.
- **Активні** — картка кожного квесту зі станом і прогресом, журнал.
- Обережна робота з лімітами Discord: заголовки `X-RateLimit-*`, повтор після 429, спільний кеш списку квестів.

## Збірка
Потрібен [Rust](https://rustup.rs/) (stable, MSVC).

```
cargo build --release
```

Готовий файл: `target\release\discordunlocker.exe`. Поруч із ним програма створює `settings.json`, `played.json`, `detectable.json` і папку `games\`.

## ⚠ Важливо
- Для квестів потрібен токен акаунта Discord. Він зберігається у `settings.json` відкритим текстом — **ніколи не публікуйте цей файл**.
- Використання токена користувача в сторонніх програмах порушує умови користування Discord; акаунт можуть заблокувати. Використовуєте на власний ризик.
